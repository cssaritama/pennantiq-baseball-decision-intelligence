# Module 13 — Dynasty Benchmark

**Status:** roadmap / public research benchmark

Purpose: compare publicly observable performance patterns of repeat champions and elite organizations without claiming access to proprietary club methods.

Initial research anchors:

- 1998–2000 Yankees three-peat;
- 2024–2025 Dodgers back-to-back championships;
- other historical repeat champions where comparable data exists.

The module may study depth, run prevention, run differential, roster resilience, postseason leverage outcomes, availability, platoon usage and other public indicators. It must not infer internal decision processes as facts.

Promotion gate: reproducible historical dataset, era controls, explicit source licensing, pre-registered metrics and out-of-sample validation.
