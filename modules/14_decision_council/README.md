# Module 14 — Decision Council

**Status:** implemented public baseline / advanced Team roadmap

The public version uses a deterministic orchestrator with four specialist evidence producers:

1. Pitching Strategy;
2. Starter Pulse;
3. Context Intelligence;
4. Opponent Adaptation.

The Chief Strategy layer synthesizes the reports and an evidence gate can force abstention. The human analyst remains accountable for the final choice.

The private Team roadmap moves the same contracts to Google Cloud Vertex AI Agent Builder / Agent Development Kit, adding team-specific tools, memory, evaluation and access controls.
