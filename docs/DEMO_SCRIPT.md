# 90-Second Demo Script

1. “Baseball has more data than ever. The scarce resource is not information; it is a decision the organization can explain and learn from.”
2. Open Matchup Lab and select a pitcher, hitter and count.
3. Show Plan A, Plan B, Avoid and Evidence Strength.
4. Open adaptation signals and explain that they are observable changes, not mind reading.
5. Open Shadow Mode: recommendations are generated using only information available before each historical date.
6. Open Trust Ledger to show provenance, method and limitations.
7. Close: “PennantIQ does not replace baseball judgment. It gives every decision evidence—and every series a memory.”
