# Public Release Scope

This repository is the certificate/portfolio surface for PennantIQ.

## Included publicly

- runnable application and deterministic demo data;
- real-data acquisition adapters and documented data boundaries;
- RAG/retrieval code and evaluation;
- Decision Council baseline;
- Starter Pulse, Matchup Lab, context analysis and Shadow Mode;
- monitoring, feedback and decision-memory baselines;
- tests, Docker/Compose, CI and reproducibility assets;
- GCP reference architecture;
- public research case studies, responsible-use boundaries and roadmap;
- open-core plugin interfaces for future private extensions.

## Intentionally excluded

The public certificate repository does not include founder master prompts, investor data-room indexes, GTM plans, detailed virality/outreach plans, provider partnership maps, or private-repository blueprints.

Those materials do not improve course reproducibility and are maintained separately as founder/private strategy.

## Important

The public repository is evidence of what can be demonstrated. The roadmap is a statement of future intent, not implemented capability.
