# PennantIQ Roadmap

The roadmap protects credibility: no module is described as implemented until it has code, permitted data, tests, evaluation and an abstention or failure policy.

## v0.1 — Initial Open-Core Decision Intelligence Prototype · implemented baseline

- team-agnostic organization profiles;
- Command Center;
- Starter Pulse;
- Matchup Lab;
- Decision Council with four specialists and Chief Strategy synthesis;
- Time × Space Context Matrix;
- Opponent Adaptation Signals;
- Shadow Mode;
- Ask PennantIQ;
- Decision Ritual and SQLite memory;
- Trust/monitoring dashboards;
- frozen real New York results snapshot;
- Statcast and Retrosheet acquisition connectors;
- GCP architecture and Terraform foundation;
- open/private plugin contracts;
- New York showcase configuration;
- Dodgers Dynasty Benchmark methodology;
- Zoomcamp evaluation and packaging.

## v0.2 — Real-Data Validation Release

- create a legally defensible frozen pitch benchmark;
- point-in-time player/roster enrichment;
- park, travel, weather and opponent-strength adjustments;
- starter-role validation;
- hierarchical / empirical-Bayes context models;
- real Yankees and Mets historical Shadow Mode case studies;
- repeat-champion historical benchmark dataset;
- evaluate Decision Council against simpler single-workflow baselines;
- close-decision UI and calibration charts;
- screenshots, hosted demo and release automation.

## v0.3 — Prospective Shadow Pilot

- generate plans before real games;
- timestamp and cryptographically version evidence packages;
- collect analyst usefulness ratings;
- compare with observed decisions afterward;
- measure preparation time, evidence completeness, abstention, calibration and override rate;
- publish only aggregated results permitted by participants.

## v0.4 — GCP Agentic Reference Deployment

- Cloud Storage landing zone;
- BigQuery governed data products;
- Dataform transformations;
- Vertex AI Agent Builder / ADK Decision Council;
- Agent Engine or Cloud Run runtime;
- BigQuery Vector Search / Vertex AI Search;
- model/tool/prompt trajectory logging;
- tenant-aware organization configuration;
- Cloud Monitoring and Looker dashboard.

## v1.0 — PennantIQ Open

- public benchmark dataset and evaluation harness;
- stable schema and plugin contracts;
- role-specific reports;
- data-quality and model-performance dashboards;
- Cloud Run reference deployment;
- documented API;
- stable release and contribution model;
- reproducible New York and Dynasty Benchmark studies.

## PennantIQ Team — private after validation

Create only when proprietary value exists:

- licensed/team-owned data connectors;
- BigQuery team data products and point-in-time feature registry;
- private Vertex AI specialist agents;
- private scouting knowledge base;
- video, tracking and biomechanics integrations;
- validated Adaptation Fingerprints;
- advanced scenario/off-policy engine;
- team-specific decision memory;
- organization policies and human approval controls;
- private deployment, IAM and audit.

## PennantIQ Integrity — future league/governance vertical

- separation of pregame/in-game/postgame features;
- recommendation and tool-call logs;
- prompt/model governance;
- time-based feature controls;
- AI system registry;
- audit reports and competitive-integrity controls.

## Whole-game modules

### Pitching and bullpen

- starter form and preparation;
- bullpen availability and leverage;
- matchup chains;
- catcher/game-plan alignment;
- pitch design and development.

### Offense

- lineup/platoon scenarios;
- swing-decision plans;
- pinch-hit / bench decisions;
- baserunning.

### Defense

- positioning and range context;
- route and arm decisions;
- catcher / ABS context.

### Front office

- roster construction;
- transaction scenarios;
- player acquisition and development;
- contract/value research when data rights allow.

### Organizational intelligence

- decision memory;
- repeat-champion benchmark;
- cross-series learning;
- model drift;
- analyst/coach knowledge capture.

## Suspended until evidence and governance exist

- injury diagnosis or medical prediction;
- autonomous coaching;
- prohibited or unauthorized live dugout recommendations;
- championship guarantees;
- biometric ingestion without consent and governance;
- causal counterfactual claims from observational data alone.
